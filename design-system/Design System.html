§01

Frame · the brief, in one breath

This is the operating manual for everything Project Agent renders — the morning triage briefing, the portfolio dashboard, the PR description that lands at 8:02 a.m. The aesthetic was already promising. It was not yet a system. This document makes it a system.

Two modes share one set of tokens. Editorial for spec artifacts read once — generous whitespace, type-driven hierarchy, dark editorial palette. Operational for reports scanned at speed — denser tables, faster rhythm, color paired with iconography because color alone is never enough. Drop-shadows are minimal. Depth comes from type and space, not chrome.

The point of the system is that the next contributor builds a new report by composing what's here — without inventing a new token, and without re-reading every prior decision.

A token is a decision someone already made on your behalf. A system is a chain of those decisions you can defend in writing.

§03

Status · what the pipeline emits

The pipeline writes five things into every indicator: a color (green/yellow/red), a lock bit, a source bit (manual or derived), the timestamp, and the rationale. Color does not carry meaning alone — every state pairs with a glyph and, where applicable, a pattern. Color-blind safe; print safe.

§08

Voice · notes & next steps

Brand voice

Quietly confident. Slightly dry. Never cute. Write microcopy your design system can live up to. Section TOC labels stay short and grounded — Frame · Common Ground · By Dimension. Status labels are factual — Current · Next · Planned · OSS. Callouts borrow their name from what they're for — The honest summary · Closing read · Open question 03.

Bilingual

English + Portuguese-BR are first-class. Section labels, button text, badges localize. Dates stay ISO YYYY-MM-DD for machine readability; the surrounding label translates — Last updated · Última atualização. The triage briefing has been running in pt-BR successfully — every primitive in §06 reads cleanly in either.

Accessibility

Color is never the sole carrier of meaning. Status colors pair with glyphs (check / exclamation / cross). Severity badges pair color with shape (triangle / circle / square). Locked cells pair color with diagonal hatch. Tables get proper <th scope>. Hover-popovers have keyboard-focus equivalents. Text contrast meets AA on dark; AAA on light.
