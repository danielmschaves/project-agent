Multi-Agent (Phase 5b)

Why the boundary matters

Idempotence Model

The contract that makes daily cron safe

Four runs of the same source, illustrated. The single property that lets the system run on a schedule without operator anxiety — anchored at two layers, neither of which depends on LLM determinism.

Idempotence is enforced at two layers: the source manifest (file-level hash, skips re-ingest) and the LLM response cache (prompt-version × source-hash, replays byte-identical extraction). The supersedes-chain (Runs 3 and 4) keeps the log honest about which version of a source produced which events without ever mutating in place. v0.2 note: the v0.1 model dedup'd on sha256(payload + source_ref) where payload was LLM-extracted — i.e. it relied on LLM determinism. That was the wrong primitive. The current model dedupes at the source layer (where determinism is real) and uses the LLM cache to make parse output deterministic by construction.
